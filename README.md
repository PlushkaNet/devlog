**Simple devlog web server with admin access for me to use behind proxy**

## Installation
```
sudo bash -c "$(curl https://raw.githubusercontent.com/PlushkaNet/devlog/refs/heads/master/scripts/install.sh)"
```

## Remove
```
sudo bash -c "$(curl https://raw.githubusercontent.com/PlushkaNet/devlog/refs/heads/master/scripts/remove.sh)"
```

Notes:
- **all static web pages must be in the same folder with binary**
- **remove.sh removes all data including `pages.db`**
